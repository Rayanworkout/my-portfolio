Services

Relier vos outils et mettre vos données au service des équipes.

Je développe des échanges entre logiciels, ERP et bases de données, dans les deux sens. Je prends aussi en charge la qualité des données, les applications qui les utilisent et leur mise en production dans votre environnement.

Connexion des outils

Faire circuler les données entre logiciels, ERP et bases

Je définis les échanges dans chaque sens : les données peuvent entrer dans un ERP ou une base, puis les mises à jour repartir vers les autres applications. Selon les outils en place, ces échanges passent par une API, des fichiers ou des traitements planifiés.

Les transformations, les contrôles et le suivi des synchronisations permettent de repérer les échanges en erreur.

Données

Préparer une migration ou une reprise de données

Lors d’un changement d’outil, je repère les données à conserver, fais correspondre les champs et vérifie le résultat avant la bascule.

Le travail peut comprendre des scripts de reprise, des règles de transformation et une documentation des choix effectués.

Développement

Applications métier et API REST

Je développe l’application ou l’API autour des tâches de vos équipes : saisir, consulter et partager l’information avec les droits d’accès adaptés.

Selon le projet, j’utilise Python, Django, PostgreSQL, JavaScript et des API REST.

Automatisation

Traitements planifiés et tableaux de bord

Je mets en place des traitements pour préparer les données dont vos équipes ont besoin. Leur exécution peut être suivie afin de repérer les erreurs.

Ces traitements peuvent alimenter un tableau de bord métier ou comptable.

Production

Mise en production et CI/CD

Je prépare le déploiement dans votre environnement et documente les étapes utiles à l’exploitation de l’application. J’ai déjà déployé des applications sur des serveurs internes avec des pipelines CI/CD.

Je peux aussi accompagner l’équipe qui prendra l’outil en main.

Échanger

Un échange de données ou une application à cadrer ?

Envoyez-moi votre contexte, les outils concernés et le résultat recherché. Je vous répondrai pour préciser la suite.
